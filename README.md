# Image Upload App

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## How to run the App

In the project directory, you can run:

### `npm install`
### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.

-----------------------------------------------------------

## App functionality

Image Upload App is a simple application that allows users to:

- Upload image files
- Display images in the Browser
- Search for images by name
- Delete images from the list
- Store image data using localStorage simulating an API

## Limitations 

- Image file size greater than ~1MB can cause storage overflow
- Basic functionality of Image selection and uploading
- Single Image upload at the time
- Just a few Images file types allowed (.png, .jpeg, .jpg, etc)
- Basic Alerts and error messages
- Basic Search functionality
